% Annotation-extraction fixture: COMMENTS
%
%   pdflatex base.tex        (one run is enough; no aux dependencies)
%
% TOPIC: the FIELDS of an annotation as the producer chose to write
% them -- comment text and its encoding, author, dates, colour. Every
% item is an ordinary highlight over plain text. What varies is what
% gets typed or chosen in the viewer, not the document.
%
% Not here: characters under a quad (tests/text), declared text
% (tests/actualtext), page attributes (tests/page), how many records
% come out (tests/inventory), byte sequences no viewer can be asked to
% emit -- PDFDocEncoding, a UTF-8 BOM, embedded NULs, an UNPAIRED
% surrogate -- which are tests/structure.
%
% ---------------------------------------------------------------------
% ASSERTION VERSUS SURVEY
%
% The producer chooses the encoding, the palette and the date format,
% and we do not get a vote. So two different things are being measured
% and they must not be confused:
%
%   THE ASSERTION is round-trip fidelity. Whatever encoding a producer
%   picks, the text that comes out must equal the text that was typed.
%   That is testable and every item states it.
%
%   THE SURVEY is which mechanism the producer picked -- UTF-16BE or a
%   single-byte encoding, RGB or CMYK, which of the three date forms.
%   That has no right answer and belongs in PRODUCERS.md. It is also
%   the only way to find out whether PDFDocEncoding, which sits in
%   tests/structure on the strength of the spec alone, is written by
%   anything real.
% ---------------------------------------------------------------------
%
% EVERY TARGET IS THE SAME SENTENCE, as in tests/page, so that
% expected.json is one covered_text repeated and a failure is
% unambiguously about the comment field rather than about text
% recovery. No target contains a ligature, an accent or a hyphen.
%
% Contains NO annotations. Annotate base.pdf by hand in each program
% following ANNOTATIONS.txt, and save as base-<tool>-<version>.pdf.
%
% Deliberate choices, following tests/basic/base.tex: no hyperref,
% uncompressed, one sentinel [[CMnn]] per target.
% =====================================================================
